# 寄存器表与镜像映射

本文档是寄存器定义的唯一来源。修改本表必须同步 F103 固件、F407 映射、Python 模拟器和 Linux 点位定义。

## 1. 约定

- 协议地址一律 0-based，不使用 4xxxx 表示法。
- 测量值放在 **0x04 输入寄存器**（只读）。
- 参数、控制、状态放在 **0x03 保持寄存器**（R/W 或 W）。
- 0x03 与 0x04 是两个独立地址空间，同一数值地址可以同时存在。
- uint32 统一大端 ABCD（高字在前），起始地址偶数对齐。
- 每个从站都有 `0x00F0` 故障注入寄存器。
- Point ID 编码：`(slave_id << 8) | (space << 7) | index`，space 0 = 保持寄存器，1 = 输入寄存器，index 0–127。

## 2. Slave 1：温度与压力

### 0x04 输入寄存器

| 地址 | Point ID | 含义 | 类型 | 权限 |
|---|---|---|---|---|
| 0x0000 | 0x0180 | 设备状态 | uint16 | R |
| 0x0001 | 0x0181 | 温度 ×10 | int16 | R |
| 0x0002 | 0x0182 | 压力 ×100 | uint16 | R |
| 0x0003 | 0x0183 | 报警状态 | uint16 | R |

### 0x03 保持寄存器

| 地址 | Point ID | 含义 | 类型 | 权限 |
|---|---|---|---|---|
| 0x0010 | 0x0100 | 采样周期 ms（默认 200） | uint16 | R/W |
| 0x00F0 | 0x0101 | 故障注入模式 | uint16 | R/W |

## 3. Slave 2：电量采集

### 0x04 输入寄存器

| 地址 | Point ID | 含义 | 类型 | 权限 |
|---|---|---|---|---|
| 0x0000 | 0x0280 | 电压 ×10 | uint16 | R |
| 0x0001 | 0x0281 | 电流 ×100 | uint16 | R |
| 0x0002–0x0003 | 0x0282 | 累计电量（ABCD） | uint32 | R |

### 0x03 保持寄存器

| 地址 | Point ID | 含义 | 类型 | 权限 |
|---|---|---|---|---|
| 0x0010 | 0x0200 | 清零命令（写 1 清零，读返回 0） | uint16 | W |
| 0x00F0 | 0x0201 | 故障注入模式 | uint16 | R/W |

## 4. Slave 3：执行器

| 地址 | Point ID | 含义 | 类型 | 权限 |
|---|---|---|---|---|
| 0x0000 | 0x0380 | 输出状态 | uint16 | R |

## 6. 故障注入

```c
typedef enum {
    FAULT_NONE = 0,
    FAULT_NO_RESPONSE,
    FAULT_BAD_CRC,
    FAULT_DELAY_RESPONSE,
    FAULT_EXCEPTION_CODE,
    FAULT_TRUNCATED_FRAME
} FaultMode;
```

| 模式 | 行为 |
|---|---|
| FAULT_NONE | 正常响应 |
| FAULT_NO_RESPONSE | 不响应；30 秒后自动恢复 |
| FAULT_BAD_CRC | 响应帧 CRC 错误 |
| FAULT_DELAY_RESPONSE | 延迟 500ms 后响应 |
| FAULT_EXCEPTION_CODE | 返回预设异常码 |
| FAULT_TRUNCATED_FRAME | 发送截断帧 |

- 注入只影响当前从站。
- `FAULT_NO_RESPONSE` 生效后无法通过 Modbus 清除，依赖 30 秒自动恢复或调试串口命令。
- 故障注入不得导致看门狗复位或影响其他从站。

## 7. F407 镜像映射

镜像按逻辑点建模，一个条目对应一个点位，不对应单个 16 位寄存器。32 位值一次性更新。

### 7.1 分区

| 分区 | 地址范围 | 说明 |
|---|---|---|
| 从站状态 | 0x0000–0x003F | 每从站 0x10 |
| 保留 | 0x0040–0x00FF | — |
| 测量值 | 0x0100–0x01FF | 每从站 0x40 |
| 控制/参数 | 0x0200–0x02FF | 每从站 0x40 |
| 通信统计 | 0x0300–0x03FF | 每从站 0x40 |
| 系统健康 | 0x0400–0x04FF | 全局 |

### 7.2 映射公式

```text
镜像地址 = 分区基址 + (slave_id - 1) * 0x40 + 点内偏移
```

- 点内偏移是本文档分配的紧凑索引（0x00–0x3F），不是从站本地寄存器地址。
- 状态区每从站 0x10；系统健康区为全局。

### 7.3 示例

Slave 1 测量值：

| 点位 | 从站地址 | 镜像地址 |
|---|---|---|
| 设备状态 | 0x04:0x0000 | 0x0100 |
| 温度 | 0x04:0x0001 | 0x0101 |
| 压力 | 0x04:0x0002 | 0x0102 |
| 报警状态 | 0x04:0x0003 | 0x0103 |

Slave 2 测量值：

| 点位 | 从站地址 | 镜像地址 |
|---|---|---|
| 电压 | 0x04:0x0000 | 0x0140 |
| 电流 | 0x04:0x0001 | 0x0141 |
| 累计电量低字 | 0x04:0x0002 | 0x0142 |
| 累计电量高字 | 0x04:0x0003 | 0x0143 |

> 累计电量在镜像中仍是一个 32 位逻辑点，占用两个 16 位镜像地址；更新时必须一次性写入两个半字。

Slave 3 控制：

| 点位 | 从站地址 | 镜像地址 |
|---|---|---|
| 输出控制 | 0x03:0x0010 | 0x0280 |
| 目标值 | 0x03:0x0011 | 0x0281 |
| 故障注入模式 | 0x03:0x00F0 | 0x0282 |

## 8. 数据库映射

`device_data` 表按逻辑点存储：

| 字段 | 说明 |
|---|---|
| gateway_id | 网关编号 |
| slave_id | 从站编号 |
| point_id | 本文档定义的稳定 ID |
| register_space | 0 = 保持寄存器，1 = 输入寄存器 |
| register_address | 从站本地起始地址 |
| value_raw | 原始 uint32 |
| scale | 缩放系数 |
| quality | 0 正常、1 过期、2 通信错误、3 越限 |
| timestamp | Linux 收到报文的 Unix 毫秒（UTC） |

一个逻辑点一行，不按 16 位寄存器拆行。
